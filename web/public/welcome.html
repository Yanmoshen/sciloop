过去是「文献一个工具、翻译一个工具、写作一个工具、实验记录又一个表格」；现在它们共用一个库、一份证据链。

MODULES

一个入口，四个模块

从找文献到跑完研究链，四块拼在一起，共用一个库、一份证据。

文

文献调研

四个公开学术源按条件检索与抓取，下载全文并解析成可引用的证据；抓到什么、没抓到什么逐源留痕。

光

Idea 生成

在文献与知识库里找研究缺口，生成可执行的研究构思，并给出可行性与价值评估——不是凭空出点子。

库

知识库

条目与正文分离的文件型知识库：可检索、可备份、可迁移，每条都带来源，不依赖数据库才能读。

链

研究链

把构思编排成一条可复跑的研究链，节点间有规则校验与调度——程序控流程，模型做研究。

WORKFLOW

从一个研究问题，到一个平台内闭环

01

提出问题

用一句话描述你想研究什么。系统按问题自动规划调研路径，不用先填一堆表单。

02

自动调研

抓取文献、下载全文、翻译、提炼证据——都在同一个库里边跑边留痕，数据源健康全程可见。

03

研究者批准

高风险动作（改写结论、动你的文件、花额度跑实验）先问再做；你可以批准、修改或直接接管。

04

实验与撰写

受控执行环境里跑实验，白名单、超时与输出上限写死在代码里；结论都挂着可点开的证据。

05

导出交付

交付物随附实验护照与决策日志；同一个平台里，从问题到交付不需要导出再导入。

SECURITY

Agent 的安全边界

它能碰什么、碰不了什么，都写在代码里；不靠提示词自觉，也不靠"你记得别让它乱来"。

⚑

命令执行分权

只读命令（如查看状态、列出依赖）直接放行，写、删、装包等一律先出批准卡，参数在你批准时冻结——批了之后不能再被改写。

▣

受限执行环境

实验只能经模板白名单调用，参数过校验、样本量设上限、单次运行有时限、输出有总量上限；不提供任意 shell、eval、运行时装包的入口。每次运行落成一份实验护照。

⇄

出网与凭据收紧

模型出网只允许白名单域名，内网与本机地址一律拒绝；管理密钥只存服务端，写接口需要管理员令牌，密钥不明文落库。

INTEGRITY

学术诚信

这套东西是拿来写论文的，所以「不编」不是一句产品承诺，而是写进契约的硬约束。

零

取不到就说取不到

论文元数据、引用数、指标、覆盖率——拿不到一律留空并写明原因；论文本身没报告的信息标成 unknown，不替它猜一个看起来合理的值。

真

不把失败包装成成功

数据源没配密钥或没响应，就如实显示"未配置 / 降级"并跳过；回放结果必须标记为回放，不冒充实时实验；解析失败的论文只保留摘要级证据，不生成看着完整的卡片。

证

每句结论都能回到原文

结论挂着证据键，定位用引文 + 字符偏移并绑定文档版本（不把网页版页码当成 PDF 物理页码）；引用链接不可用时保持纯文本，绝不造一个能点开的假引用。

OPEN SOURCE

本地运行，Apache-2.0 开源

一条命令装好：Python + SQLite + 一个浏览器。文献、译文与实验记录都留在你自己机器上。
